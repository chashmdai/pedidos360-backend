Objetivo
Registrar el resultado de las pruebas de backend y frontend.

Indicador asociado

Entorno
Local, CachyOS (Linux nativo), Java 25 (Temurin), Maven Wrapper, Docker con Testcontainers 2.0.5 (Kafka Confluent 7.9.10 y MySQL 8.4.11 efímeros); Node.js con npm. Rama ep5-kafka, build del 2026-11-19T04:00Z que generó el release ep5-20261119T040026Z desplegado en AWS (scripts/ep5-build.sh). El frontend se compila con VITE_APP_BASE_PATH=/app/ y la configuración pública de Entra para la nube.
